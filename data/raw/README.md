# Original sources and samples

Data IS included:

- data-centers-share-electricity-demand.csv: unchanged OWID download supplied by Brighty; source https://ourworldindata.org/grapher/data-centers-share-electricity-demand. Source-log retrieval 18 October 2026; observations 2020, 2023-2025; percentages for all data centres, not AI alone.
- Aqueduct40_rankings_download_Y2023M07D05.xlsx: unchanged WRI workbook supplied by Harsh; source https://www.wri.org/data/aqueduct-40-country-rankings; CC BY 4.0. Source note records 22 October 2026, member confirmation pending. country_baseline sheet used; indicator periods differ.
- aqueduct40_country_baseline.csv: Harsh's saved workbook-sheet sample.
- story_country_baseline_sample.csv: integration-derived sheet sample plus source_excel_row; not an independent source.

Source hashes and coverage are in data/processed/story_metadata.json. Field definitions, units, keys, periods and transforms are in docs/DATA_DICTIONARY.md.
