# Processed data

The app reads story_electricity.csv, story_water.csv and story_metadata.json. grid_share.csv is a compatibility output.

owid_data_centres_share_clean.csv and m4_water_stress_drought.csv are preserved member outputs for standalone use and verification, not independent sources. Full fields, keys, units, coverage and transformations are in docs/DATA_DICTIONARY.md and member dictionaries. Missing values remain missing.
